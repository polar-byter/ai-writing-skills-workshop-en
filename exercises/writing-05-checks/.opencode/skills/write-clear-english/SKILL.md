# Write an understandable explanation

Write connected English explanations of a work task. Preserve supplied facts and do not claim measured benefits without measurements.

Establish the reader's task before naming unfamiliar fields. Explain current values and both selection conditions on the supplied records. Before changing a threshold or example, say what changes and why, then reconnect it with the original task. Do not invent interface details.

Before explaining unfamiliar fields or changing an example, read [reader-first.md](references/reader-first.md). Use its technique, but take data from the current task.
